# Crop reference images

These are starter visual templates bundled with the app for local reference.

## Included

- `ripe_wheat.png`: small image template for mature/grown wheat.
- `empty_field.png`: small image template for an empty/tilled field.

## Not included yet

- Growing/green wheat reference image.
- Multiple screenshots across zoom levels, lighting, and farm layouts.

These two files are copied from [PoperieDev/haydaybot](https://github.com/PoperieDev/haydaybot), from its `images/farm/grown.png` and `images/farm/empty.png` files. The source repository identifies its license as **CC BY-NC 4.0**. Attribution: PoperieDev, “HayDay Bot” (GitHub). License: https://creativecommons.org/licenses/by-nc/4.0/

Changes: files copied into this Android project's assets folder and renamed.

**Important:** these are tiny template crops, not a trained AI model and not a complete dataset. They are starter references only. The app must be tested against screenshots from the current Hay Day version before they are used for any automatic action. Use is subject to the non-commercial restriction in the source license.
