# HayDay Wheat Harvester

مشروع Android تجريبي للتعرّف بصرياً على القمح الناضج في Hay Day.

## المرحلة الحالية
- هيكل تطبيق Android وواجهة عربية أولية.
- لا توجد نقرات آلية أو حصاد تلقائي حالياً.

## خطة التطوير
1. إدخال لقطة شاشة للعبة وتحليلها.
2. اكتشاف القمح الناضج وتحديد مواضعه.
3. عرض النتائج بمربعات للتأكد من الدقة قبل أي إجراء.
4. اختبار اختلاف دقة الشاشة والزوم.

يتم بناء APK تجريبياً عبر GitHub Actions.

> أداة غير رسمية؛ قد تخالف الأتمتة شروط اللعبة ولا يوجد ضمان لسلامة الحساب.
